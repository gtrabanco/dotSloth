# Memory policy

Git and frozen contracts are authoritative for requirements, architecture, and acceptance evidence.
AWL SQLite is authoritative for execution state, leases, checkpoints, and receipts.

Serena stores and retrieves stable project knowledge for semantic navigation. Engram stores bounded session summaries, decisions, handoffs, and links to evidence. Neither store may mark work complete, replace repository evidence, or automatically promote a session observation into stable project knowledge.

Agents retrieve only relevant memory at session start and write a concise, redacted summary at session end. Promote an Engram fact into Serena only through committed documentation, an explicit human decision, an accepted architecture decision, or validator-backed evidence.
